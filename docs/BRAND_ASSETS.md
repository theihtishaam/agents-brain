# Integration icon sources

The portal bundles four small vector marks from [Lobe Icons](https://github.com/lobehub/lobe-icons), pinned to revision `55746b0b082258211121c70bd26e6878fd3bd292`. They identify the corresponding tool in the agent activity view; they are not Agent Shadow Brain branding or an endorsement. The OpenAI mark identifies Codex, and the DeepSeek mark identifies DeepSeek Harness. It does not identify which model a host is running.

The SVG artwork is unchanged. Icons load from the installed application, without a CDN or runtime dependency. The surrounding activity indicator animates; the brand artwork does not change shape. Brand names and marks belong to their respective owners. See [OpenAI brand guidance](https://openai.com/brand/).
